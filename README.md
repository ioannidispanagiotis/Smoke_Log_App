# Smoke Log

Personal daily cigarette tracker, built as a Progressive Web App for iPhone.

## Features
- One-tap logging with exact timestamps, plus undo
- Daily limit with a progress ring (green, amber, red)
- History with the ability to add or delete entries for any day
- Stats: daily average, streaks, time-of-day and weekday charts
- Cost tracking from pack price and size, with savings vs a baseline you set
- JSON backup/import and CSV export
- Works offline; all data stays in the browser storage on the device

## Install (iPhone)
1. Open the GitHub Pages URL of this repo in **Safari**.
2. Tap Share, then **Add to Home Screen**.

## Notes
- No backend, no tracking, no dependencies.
- Data lives only on the device. Export a backup regularly: deleting the
  Home Screen app or clearing Safari website data erases it.
